# Déjà Vu Log

An interactive visualization of a personal déjà vu log — 40 episodes, May 2023 to August 2026, each typed into a phone note within minutes of the feeling.

Live at https://aburke225.github.io/deja-vu/

Plain HTML/CSS/JS, no build step, no libraries. The data lives in the page; the ledger renders without JavaScript. By [Andrew Burke](https://aburke225.github.io).
